 CSS TASK 4 – BOX MODEL

 Introduction

In this task, I explored the CSS Box Model by using different properties such as width, height, padding, margin and border. I applied these properties to different containers to see how they change the size, appearance and spacing of HTML elements.
 1. Width

To begin, I worked with the width property. I set the width of my first container to 500px and gave it a background colour to make the content area visible. Through this, I learned that the width property controls how wide the content area of an element is.

 2. Height

Next, I experimented with the height property on my second container by setting its height to 500px. I also applied a background colour to observe the result more clearly. This helped me understand that the height property controls the vertical size of the content area, while the width depends on the available space.

 3. Padding

After that, I explored the padding property on my fifth container. I used different padding values and noticed that the space inside the container, between the content and the border, increased. I also observed that adding more padding makes the overall size of the container larger.

 4. Margin

Then, I tested the margin property on my fourth container. I applied different margin values and observed how the distance between the container and surrounding elements changed. This helped me understand that margin creates space outside an element's border.
